## Bugs found and regression coverage

1. Platform adapters sharing one arbitrary tab could overwrite each other's browser state. Sessions now select independent tabs by preferred platform host.
2. Bilibili repeatedly reloaded Chrome cookies and prompted for Safe Storage per item. The yt-dlp instance is now locked and reused, with bounded throttling/backoff and sanitized unavailable-item handling.
3. Xiaohongshu `urlDefault` was incorrectly labelled original and rejected valid aspect-preserving WebP renditions. It is now labelled `page-default` and checked by decode, MIME, hash, and source aspect ratio.
4. Punctuation-only OCR noise aborted the entire timeline fusion. Non-comparable OCR noise is now ignored while useful spoken and visual text remains mapped.
5. Douyin root enumeration reused the currently scrolled favorite page, producing a different first item on each limited run. Root enumeration now reloads the profile, reacquires React tab nodes while clicking, and restarts at the first cursor.
6. Xiaohongshu and Douyin live response hydration/pagination changed from the sanitized fixtures. Session polling, dynamic stream-family handling, real scroll-container pagination, and lost navigation-response tolerance were added with regressions.
