# social-media-favorites-archiver
Archive, transcribe, OCR, summarize, and organize social-media favorites into a local Markdown or Obsidian knowledge base.

## Project status

The project is currently in the design-review phase. Read the
[detailed design](docs/superpowers/specs/2026-08-08-social-media-favorites-archiver-design.md)
for the proposed architecture, privacy boundaries, platform adapters, processing
pipeline, testing strategy, and phased delivery plan.
