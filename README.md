# social-media-favorites-archiver
Archive, transcribe, OCR, summarize, and organize social-media favorites into a local Markdown or Obsidian knowledge base.

## Project status

The project has completed its first external design review and now has an
execution-ready implementation plan. The revised architecture covers two-stage
sync, collection-membership correctness, ASR/OCR timeline fusion, Apple Silicon
backends, and safe Markdown updates.

- Read the [detailed design](docs/superpowers/specs/2026-08-08-social-media-favorites-archiver-design.md) for architecture and product decisions.
- Follow the [implementation plan](docs/superpowers/plans/2026-08-08-social-media-favorites-archiver-implementation.md) for the task checklist, tests, live validation matrix, and publication gates.
